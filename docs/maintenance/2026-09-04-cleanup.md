# 2026-09-04 项目整理记录

起点：HEAD `debbac2`，并有前几轮尚未提交的 runtime/契约/插件改动。本轮在该工作树上修复整理，未重置已有工作。

## 完成的整理

| 范围                    | 修复与影响                                                                                                       |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Runtime 输入边界        | IR 方法检查移到 kernel run 之前，删除源码关键字正则的准入判断；专属 target 拒绝混合方法 IR                       |
| 科学证据                | 移除仅凭变量名套用 M/M/1/指数衰减公式；把理论断言保留在明确参考模型测试中                                        |
| Conformance             | 总 passed 由实际检查的合取产生；NaN/Infinity、倒序轨迹和 replay 差异会失败                                       |
| DEVS 证据               | 空 LPLT 不再当作 transition trace；返回明确的未导出状态                                                          |
| 随机数与 replay         | entrypoint 把 request.seed 传到真实运行参数；冲突 seed 拒绝；replay 用实际 seed/count；不覆盖调用者 reps         |
| 插件结构                | 四份 runtime 封装合并为一个源码模板；构建复制成四个自包含包；不再自动批准目录中任意新增权限                      |
| HTTP 执行               | 移除静态 fallback；每次读取活动 registry；修正 400/404/405/413、UTF-8 分片、请求 pin 处理                        |
| Artifact 归档           | 执行相关代码从 catalog bridge 拆出；保存完整请求和 evidenceRef；幂等重试/冲突分开；未提交归档不再冒充成功持久化  |
| ExecutionTargetRegistry | head target 支持指定 revision，结果必须绑定实际请求 pin；校验 seed 和 evidence 一致性                            |
| Node host               | target owner/duplicate 在切换前校验；失败候选销毁；Worker 初始化/执行超时和退出清理有所增强                      |
| Browser registry        | SSE 使用 remote generation 而非本地 render revision；generation 0 可加载；变更后的合成结果不保留无效签名         |
| 契约                    | Palette canvas 复用 CanvasEngineId 的破坏性变更明确记录并更新单个 baseline 字段；补齐 required-property 门禁漏洞 |
| MSVC                    | 修正本机 GBK `/showIncludes` 与 Ninja 前缀不匹配，避免头文件更新后漏编译                                         |
| 文档                    | 新建文档入口、当前状态页、交接提示词；旧计划/ADR 标注历史范围；导航索引更新                                      |
