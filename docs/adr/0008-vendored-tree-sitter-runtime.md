# ADR-0008: Vendored tree-sitter C Runtime under `dsl/compiler/third_party/`

- **Status**: Accepted
- **Date**: 2026-08-04
- **Deciders**: LogicPilot Phase 2

## Context

The DSL compiler (Phase 2b, task #6) links the checked-in grammar artifact
`dsl/tree-sitter-logicpilot/src/parser.c` (ADR-0005, ABI 15, generated by
tree-sitter CLI 0.26.11) against the tree-sitter C runtime to parse `.lp`
sources. The runtime must be available to the C++ build on every supported
toolchain (Windows MSVC, MinGW, Linux clang) with **zero build-time tool
downloads** — mirroring the ADR-0005 discipline for `parser.c`.

Options considered:

1. **vcpkg `tree-sitter` port** — the port exists at the right version
   (0.26.11), but ADR-0002 pins vcpkg to *simulation-kernel* dependencies;
   the parser/runtime pair is a *source artifact* of the DSL frontend: its
   ABI must always move in lockstep with the checked-in `parser.c`. A port
   version bump would silently decouple the two.
2. **FetchContent at configure time** — network dependency at build time,
   non-reproducible, rejected for the same reasons as ADR-0005.
3. **Vendor the minimal runtime into the repo** — chosen.

## Decision

- Vendor the tree-sitter **C runtime library, version v0.26.11** (tag
  `v0.26.11`, matching the CLI that generated `parser.c`), into
  `dsl/compiler/third_party/tree-sitter/`:
  - `include/tree_sitter/api.h` — public C API.
  - `src/` — `lib/src` verbatim (built via the upstream amalgamation unit
    `src/lib.c`; WASM support stays compiled out, no `TS_FEATURE_WASM`).
  - `LICENSE` (MIT) and `VENDORED.txt` provenance marker (version, tag,
    SHA512 of the release tarball as pinned by the vcpkg portfile).
- The runtime is compiled as a small static library `tree_sitter_runtime`
  by `dsl/compiler/CMakeLists.txt`; **no tree-sitter CLI is ever invoked
  during builds** (extends ADR-0005 to the runtime).
- Upgrading is a deliberate act: replace the vendored tree, bump
  `VENDORED.txt`, regenerate `parser.c` if the ABI changes, and commit
  everything in one change.

## Consequences

- Positive: hermetic builds; runtime ABI is reviewed next to the parser it
  serves; ~780 KB of vendored source, no binaries; works on every toolchain
  with a C11 compiler.
- Negative: deviation from ADR-0002's "vcpkg only" rule, justified above
  (source-artifact ABI pairing, not an acquired dependency); vendored code
  must be kept warning-suppressed and untouched (no local patches — any
  needed patch becomes a fork decision recorded in a new ADR).
